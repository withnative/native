# Contributing to Native

Native is developed privately by AI Native Work Inc. This repository is a
curated, read-only source release; it is not the development upstream.

We do not accept external code, documentation, patches, pull requests, or other
contributions. Please do not open pull requests or submit patches. No DCO or CLA
process is offered because contributions are not accepted.

GitHub Issues and Discussions are not supported feedback or support routes for
this repository. For current product information and ways to contact the Native
team, visit [withnative.ai](https://www.withnative.ai/). That route is separate
from this repository and does not create a contribution or support process
here.
