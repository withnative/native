# Native capability and evidence map

This map is for evaluating what the curated Native snapshot actually supports.
It complements the product narrative in the root README: claims here stay close
to their implementation, executable evidence, and limits.

The private upstream boundary is the selection authority for the snapshot.
The public `native-boundary.json` is a generated, target-native receipt that
describes and validates only the published tree.

Maturity in this map describes selected implementation and executable evidence.
The README roadmap describes what comes next.

## Maturity labels

- **Current** — implemented in this snapshot, with public implementation and
  executable evidence.
- **Partial** — a real bounded implementation exists, but not the complete
  product or support surface a broad reading might imply.
- **Experimental** — implemented for evaluation or interoperability work, with
  an explicitly unstable or gated contract.
- **Directional** — a design direction or protocol seam, not a supported
  present-tense capability.
- **Held** — exists outside this snapshot. Held paths and private operated
  evidence never substantiate a claim in this map.

## Agent-authored tabs

The alpha tab proof separates an authored view from the authority to run it.
An agent can produce an HTML artifact and declare its input needs. The selected
backend pins the source and declaration, renders preview bytes against sample
input, and records a person's verified adoption before a launch. Reads are
executed by the host under the current viewer's authority. The two selected
packages show distinct read-only views, not a reusable marketplace catalog.
The browser shell, where a person sees and adopts a tab, remains held.

## Workspace feedback

The current feedback is tied to specific contracts. For example, previewing
`Document kind:decision` can report that `decision` is governed under
`Resolution`. Creating that combination still preserves the supplied type and
kind, warns, and quarantines it from governed dispatch; the warning does not
reclassify the record. An honest novel kind remains available. Proposed facet
feedback evaluates declared shapes and vocabulary facts, without interpreting
the candidate's prose.

A stale guarded body write returns the record's identity and current digest
and timestamp, with instructions to reread, merge, and retry. It writes nothing
and leaves reconciliation to the caller. These checks are **Current**, while
the broader workspace feedback surface is **Partial**. Semantic
judgment, placement critique, conditional repository obligations, and substantive
review of the work are **Directional**. Neither a successful write nor a clean
shape preview establishes that the content is correct or complete.

## Evidence boundary

Upstream also describes hosted services, the commercial Workbench,
operated release systems, and private CI evidence. Those materials live
upstream and are outside the curated snapshot. In particular:

- source for the hosted HTTP gateway, authentication/catalog composition, and
  commercial Workbench is **Held**;
- operated deployment receipts and generated backend-attestation reports are
  **Held**;
- the selected node exposes `mcp-stdio` and `conformance`; it does not expose a
  hosted `serve` or operator binary;
- the presence of backup or migration library seams does not prove a selected
  operated backup service or cross-backend recovery workflow.

If a public claim cannot be supported by a selected path or a command runnable
from this root, treat the claim as unproven for this snapshot.
