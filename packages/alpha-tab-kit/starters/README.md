# Source-only starters

These are complete HTML documents, not npm entry points. Install using the
matching declaration. Native supplies `window.native.kit` core major 1.
`record-reader.html` uses the 1.7.0 record helpers and needs the v2 declaration.
The meeting-notes starter requires core 1.7.13 and uses `useRecordList.create`
with shared pending actions and default page recovery. Captured requests survive
component unmounts for the page lifetime; this does not promise durable local
creation. Replace its folder ID with the person's actual chosen folder.

Agents with only Native MCP read `app-builder-1.0.0` for the complete source,
creation, preparation, installation and guarded edit journey. That guide is the
canonical source; tests compare these convenience copies with its exact HTML
and declarations and the browser proof executes those guide bytes.
